Ultra Beast rifts v96

All eleven: Nihilego, Buzzwole, Pheromosa, Xurkitree, Celesteela, Kartana, Guzzlord, Poipole, Naganadel, Stakataka and Blacephalon. All reuse the existing animated game sprites and native combat scaling. Normal legendary rift rolls become Ultra Beasts. If the native roll was a shiny legendary, it is kept exactly as rolled. Golden elite rifts are unchanged.

Rare Ultra Wormholes: a 25% roll every 180 seconds of active gameplay, only when no other rift/den/boss/special interior is active. The host rolls in co-op and broadcasts the selected species. The event opening lasts 80 seconds. A white/cyan aperture, rotating pink/cyan filaments and branching electricity follow the user’s wormhole references; the Ultra Beast appears inside the opening and its cry plays. Enter the portal to fight/recruit it in a native rift arena. The portal itself grants nothing.

Only a won Ultra Beast rift grants a new Ultra Beast, once per arena. Wild waves, gacha and legendary-den pools exclude Ultra Beasts. Existing collection data is preserved. This changes acquisition rules; it does not delete already owned Ultra Beasts. The native shiny roll is not rerolled by the scripted legendary-shiny adapter.

Co-op arena and event packet behavior is covered by tests; live multi-device play was not performed.
