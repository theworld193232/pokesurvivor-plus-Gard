# Ralts and Kirlia skin headshots v89

Built on the supplied `pokesurvivor-plus-Gard-main (4).zip` (gard-v88).

Adds forty matching Witch skin portraits: ten expressions each for normal/shiny Ralts and normal/shiny Kirlia. Normal portraits match the new teal hair, neon-green horns and dark outfits. Shiny portraits use purple/lavender hair and trim. The art retains the species' original portrait silhouettes and expression poses; no hats or Mega accessories are added to these stages.

The move-bar HUD, active/benched team headshots and selection portrait elements now choose the corresponding species and palette. Existing ten-second emotion holds, low-health worry/pain, level-up happiness, anger after repeated hits, life-loss tears and revive moods apply to the selected Witch Ralts/Kirlia skins too. Gardevoir's existing art and pose controls remain unchanged. Original appearances and other accounts retain their original portraits.

Install: merge this update into the supplied latest game's root beside index.html, replace matching files and hard refresh. This is an update archive for that full game.

New assets:
- `assets/ui/witch-portraits/ralts-emotions-v89.png`
- `assets/ui/witch-portraits/kirlia-emotions-v89.png`

Both are 5-column/4-row expression atlases. The first two rows are normal and the last two shiny. Each palette's reading order is Normal, Happy, Inspired, Joyous, Worried, Angry, Crying, Teary-Eyed, Sad, Pain.

Sprite animations, skins, battle balance, terrain, AI, audio and save progression from the supplied game are retained. The existing portrait flat-folder compatibility fallback also updates both palette entries of a shared sheet when needed.
